# Escopo do produto

## Problema

Bots para Discord normalmente exigem código, configuração fragmentada e manutenção manual. Juicy Guilds pretende transformar essa operação em módulos visuais, reutilizáveis e auditáveis.

## Usuários iniciais

- Dono de guilda.
- Administrador com permissão para configurar o Bot.
- Operador que acompanha execuções e erros.

## Capacidades do MVP

- Autenticar com Discord.
- Selecionar uma guilda administrada.
- Criar um workflow visual.
- Configurar nós de conteúdo, interface, lógica e ação.
- Validar e publicar uma versão do workflow.
- Executar o fluxo no Bot.
- Consultar logs básicos e falhas.

## Fora do primeiro MVP

- Marketplace público de módulos.
- Execução de código arbitrário de terceiros.
- Automação multicanal além do Discord.
- Faturamento complexo e planos corporativos.
