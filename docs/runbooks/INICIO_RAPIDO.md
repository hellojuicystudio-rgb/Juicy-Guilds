# Início rápido para colaboradores

## Pré-requisitos planejados

- Node.js 22 ou superior.
- pnpm 10.
- Git.
- Docker apenas quando a infraestrutura for definida.

## Nesta fundação

```bash
node tools/validate-structure.mjs
```

O comando confirma que as fronteiras, documentos e registros obrigatórios existem. Ainda não há dependências para instalar nem aplicações executáveis nesta etapa.
